# Colors-COP-4331
Files and instructions for Colors Web Application for COP 4331


## ABOUT
This repository provides a basic web app that can store a collection of colors input by a user into the database. Valid users are able to login, search for a color they have added, and see a list of additions made. *NOTE* This App does not support the addition of new users.


## Setup
To run this web application please fork and pull the repository.
The application requires the use of a website so hosting and a domain will be needed for users access remotely. All visual front end content is included, but some changes are needed to connect to the API and allow functionality.
